## 特別支援教育 × 金融リテラシー × ゲーミフィケーション — 日本初「おこづかいクエスト」無料公開

**お手伝い＝冒険クエスト。「はたらく → もらう → つかう/ためる/ふやす」を子供が体で覚える、家族向けマネー教育アプリ**

---

### 概要

「おこづかいクエスト」は、子供がお手伝い（＝クエスト）を達成して報酬を得る体験を通じ、**労働の対価・貯蓄・投資の基礎**を自然に学べるWebアプリです。

米国で年間19ドルの有料サービスとして成長する「BusyKid」にインスパイアされ、**完全日本語・ふりがな対応・無料**で提供。未就学児から中学生、特別支援教育の現場まで幅広い子供が利用できるよう、ユニバーサルデザインを徹底しています。

**URL:** https://otetsudai-bank-beta.vercel.app

### 開発の背景

#### 日本に「子供向けフィンテック」が存在しない

米国では BusyKid、Greenlight、GoHenry など「子供がお手伝いで稼ぎ、カードで使い、株に投資する」アプリが急成長し、数百万世帯が利用しています。一方、日本では——

- 完全日本語対応のお手伝い管理アプリが**ほぼ存在しない**
- 「お手伝い × 投資体験」を組み合わせたサービスは**ゼロ**
- 特別支援教育に対応した金融教育ツールは**皆無**

2022年度から高校で金融教育が必修化されましたが、小学生以下や特別支援教育の現場で使える実践的ツールは整備されていません。

#### 特別支援教育の現場課題

知的障害のある子供たちにとって、「お金」は最も身近でありながら最も理解が難しい概念の一つです。

- 抽象的な「数字」としてのお金が実感しにくい
- 「働く → もらえる」の因果関係を繰り返し体験する機会が限られる
- 既存の教材は紙ベースが中心で、即時フィードバックがない

本アプリは、ABA（応用行動分析）のトークンエコノミーシステムの考え方を取り入れ、**「行動 → 即時強化（報酬）」のサイクルをデジタルで可視化**することで、この課題に挑みます。

### 製品の特徴

#### 1. 「はたらく → もらう」を体で覚える仕組み

お手伝いを「クエスト（冒険の任務）」として提示。完了報告すると親が承認し、報酬がウォレットに加算されます。

- 報酬は自動で**3つのウォレットに分配**
  - 赤「つかう」 — 日々の買い物に使えるお金
  - 青「ためる」 — 目標に向けて貯金するお金
  - 緑「ふやす」 — 投資シミュレーションに回すお金
- 分配比率は親がスライダーで設定（例: つかう30% / ためる50% / ふやす20%）
- **「1つのお手伝いで、3つのお金の使い方を同時に体験する」** 設計

#### 2. 子供の主体性（エージェンシー）を育む

単なる「親に言われたことをやるアプリ」ではありません。

| 機能 | 内容 |
|---|---|
| じぶんクエスト | 子供が自分でお手伝いを考えて親に提案 |
| つかう申請 | 「このおもちゃが欲しい」を自分の言葉で申請 |
| ちょきん目標 | 目標金額と欲しいものを自分で設定 |
| 投資シミュレーション | 実際の株価に連動した仮想投資を体験 |

**親はあくまで「承認者」であり、子供の意思決定を見守るサポーター**です。

#### 3. ゲーミフィケーションで「続けたくなる」

| 要素 | 仕掛け | ABA/教育的根拠 |
|---|---|---|
| コインアニメーション | クエスト承認時にコインが降り注ぐ演出 | 即時強化の視覚化 |
| レベルアップ | 累計獲得額に応じて7段階の称号が変化 | 段階的な達成感の提供 |
| バッジ収集 | 「はじめてのクエスト」「3日れんぞく」等5種 | 間欠強化スケジュール |
| 承認スタンプ | 親がLINE風スタンプ＋ひとことで褒める | 社会的強化（承認欲求の充足） |
| 構造化クエスト | 「準備 → 実行 → 片付け」の3ステップ表示 | スモールステップ、見通しの確保 |

**ゲーム性はあくまで「継続の仕掛け」。主役は「労働と報酬の因果関係」の学習。**

#### 4. 特別支援教育に対応したユニバーサルデザイン

| 配慮 | 実装内容 |
|---|---|
| 視覚優先 | 色＋アイコンの二重符号化。文字が読めなくても意味が伝わる |
| ひらがな・ふりがな | 子供画面の全漢字に自動ルビ付与（辞書80語） |
| 大型タッチターゲット | 全ボタン48px以上。小さな指や不器用さへの対応 |
| 予測可能なUI | 固定フロー、順序制約の視覚表現。次に何が起きるか常にわかる |
| 罰なし設計 | 「拒否」ではなく「やりなおし」。温かいフィードバックで再挑戦を促す |
| スクリーンリーダー対応 | 全要素にaria-label / aria-hidden設定 |

#### 5. 実際の株価に連動した投資シミュレーション

子供が「トヨタの株を買いたい！」と申請 → 親が承認 → 仮想ポートフォリオに記録。

- Alpha Vantage APIで**実際の株価をリアルタイム取得**
- 日経225、TOPIX、S&P500、NYダウ、NASDAQの主要インデックス
- トヨタ、任天堂、Apple、Google等の個別銘柄24種
- 子供向けの銘柄説明（「世界一大きな車の会社」等）

**実際の金融取引は行わず、記録・学習ツールとしての利用に限定。** 実際の売買は親が自身の証券口座で行い、アプリ上で管理・記録する設計です。

#### 6. AIアドバイザー「コインくん」

Claude AIを搭載した対話型アドバイザー。

- 子供向け「コインくん」: お金の豆知識、節約のコツ
- 親向け「クエストアドバイザー」: マネー教育の実践方法、年齢別の関わり方

### 今後の展開

#### コンセプト: 「お手伝い＝冒険」×「お金＝経験値」

Habitica（タスク管理RPGアプリ、月間収益2万ドル超）の成功要因——**アバターへの愛着 × 損失回避 × ストーリー性**——を、特別支援教育のABA/トークンエコノミーの枠組みに落とし込みます。

**本質は「おもしろおかしく、労働の対価として報酬を得ることを学ぶ」こと。ゲーム性は学習意欲の喚起と継続のための仕掛けです。**

#### 設計原則（ABA/トークンエコノミー基盤）

| 原則 | 内容 | 実装方針 |
|---|---|---|
| 即時強化 | 完了→承認→報酬の流れを**目に見える形で素早く** | アニメーション演出、コイン加算の視覚化 |
| スモールステップ | 1つの作業を細かく分解、こまめな達成感 | クエストの構造化（準備→実行→片付け） |
| 罰なし | 失敗・未達成でマイナスなし | 「やりなおし」であって「ペナルティ」ではない |
| 予測可能性 | 次に何が起きるか常にわかる | 固定のフロー、視覚的な進行表示 |
| 個別最適化 | 子供ごとに難易度・報酬を調整 | 親が設定、段階的報酬（見習い→助手→リーダー） |

#### ワクワク施策ロードマップ

**Phase A: 体験の質を上げる（即時強化の強化）**

| 施策 | 内容 | 教育的根拠 |
|---|---|---|
| コイン分配アニメーション | 承認時にコインが画面に降り注ぎ、3色に分かれて各ウォレット（赤:つかう/青:ためる/緑:ふやす）に吸い込まれる演出 | 即時強化の視覚化。「働いた→もらえた」の因果関係を、言葉でなく**動き**で刻み込む。文字を読めなくても「コインが増えた」が瞬時にわかる |
| 貯金目標「あと少し！」演出 | 進捗を温度計ビジュアルで表示。80%で「あとちょっと！」応援メッセージ。達成時に花火＋バッジ。欲しいものを写真付きで登録 | 遅延報酬の理解。目標設定→達成の成功体験サイクル |
| コインくん豆知識の強化 | クエスト完了時に一言豆知識を自動表示（チャットを開かなくても）。例:「50円ためたね！500円玉10まいぶんだよ」「きょうのトヨタのかぶは100円あがったよ」 | 金融リテラシーを自然に浸透。「教える」のではなく「気づかせる」 |

**Phase B: 継続の仕掛け（習慣化とストーリー性）**

| 施策 | 内容 | 教育的根拠 |
|---|---|---|
| レベルアップ＆称号の拡張 | クエスト完了で経験値（XP）獲得。レベルアップ間隔は短め（3〜5クエストで1UP）。称号例: Lv1「はじめての冒険者」→ Lv5「お手伝いナイト」→ Lv10「おうちヒーロー」。レベルアップ時にキラキラ＋効果音＋新称号表示 | 段階的な達成感。特別支援のスモールステップと一致。「報酬」だけでなく「成長の実感」を可視化し、内発的動機づけへの橋渡し |
| デイリーストリーク | 連続クエスト達成日数をカウント（例: 🔥3日連続!）。7日連続でボーナスコイン＋特別バッジ。**途切れても罰なし**——「またがんばろう！」メッセージ付き | Duolingo型の習慣化。ただし特別支援配慮で損失回避は「軽め」に設計 |
| クエストマップ | ホーム画面を「冒険の地図」風に。クエスト達成で地図が進む（村→森→山→城）。月間ストーリー:「今月は森の国を冒険中！」 | タスク管理を「物語」に変換。学習意欲の喚起。見通しの可視化 |
| 週間ふりかえりカード | 週末に自動で「今週のまとめ」カード表示。今週のクエスト数、稼いだコイン、シンプルな棒グラフ（今週 vs 先週）。親向け: どの曜日に多いか、どのクエストが得意か | メタ認知の芽生え。労働量と収入の関係を数字で実感。色＋長さで直感的に比較できる設計 |

**Phase C: 世界観の深化（愛着と自己表現）**

| 施策 | 内容 | 教育的根拠 |
|---|---|---|
| 冒険者アバター | 登録時にドット絵キャラを選択/カスタマイズ（髪型・色・服）。クエスト達成で衣装・アクセサリーを獲得 | Habiticaの「所有感」。自分の分身への愛着が継続利用を生む。アバター変化が視覚的な即時強化 |
| 宝箱（報酬のランダム性） | 週間目標達成時に「宝箱」が開ける。中身: アバター衣装、称号、レアバッジ（ランダム）。**課金なし、努力のみで獲得（Non Pay-to-Win）** | ドーパミン報酬の変動比率強化（ABAの間欠強化スケジュール） |
| 家族パーティー | 家族＝パーティー。親子で一つのチーム。家族全体の週間目標（例: 今週10クエスト達成）→ 達成で家族ボーナス。親の承認スタンプが「応援ポイント」に | 社会的強化。親子コミュニケーションの促進 |

#### 収益化ロードマップ（Habiticaモデル準拠）

Habiticaの核心は「ユーザーの努力を可視化し、その分身（アバター）への愛着を収益化する」点にあります。

| フェーズ | 内容 | 戦略 | Habiticaモデルとの対応 |
|---|---|---|---|
| 無料期（現在） | 全機能開放 | 完全無料で生活の一部に潜り込む | 「寛大な無料ユーザー」戦略。ペイウォールを設けない潔さが強固なファンベースを作る |
| Phase 1 | 限定衣装パック（季節イベント等） | アバターの自己表現に課金 | 「機能ではなく戦利品（Loot）を売る」。アプリ機能のロックはしない |
| Phase 2 | 教材コンテンツ（金融リテラシークイズ等） | 学びの加速に課金 | プログレッション課金。新コンテンツの先行公開 |
| Phase 3 | 学校/施設向けライセンス | 管理者機能拡張のB2B | 教育現場導入による安定収益 |

**鉄則: Non Pay-to-Win。お金で勝敗が決まるのではなく、「お金を払えばより楽しく、より自分らしくなる」設計。**
